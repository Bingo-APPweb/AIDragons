# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please report security vulnerabilities to **security@yourdomain.com**.

### Response Time
- **Initial Response**: Within 72 hours
- **Critical Fixes**: 14 days
- **Regular Updates**: Every 30 days until resolution

### Guidelines for Reporting
1. Include detailed reproduction steps
2. Provide any proof-of-concept code or screenshots
3. Specify the affected versions
4. Do not disclose the vulnerability publicly until it's resolved

### Out of Scope
- Theoretical security issues with no practical exploitation scenario
- Issues that require physical access to the device
- Social engineering or phishing attacks
- Vulnerabilities in dependencies (please report them upstream)

## Security Best Practices
- Always use the latest version of the software
- Keep your environment and dependencies up to date
- Follow the principle of least privilege
- Use strong, unique passwords and API keys
- Enable 2FA for all developer accounts
